# 小瞳动效演示

这是一个独立、零依赖的 Q 版形象小项目。双击 `index.html` 即可预览，四个按钮可查看待机、检索、找到证据和无数据状态。

本目录只演示形象与动效，**没有连接筑瞳的数据库或问答逻辑**。集成时可复用 `xiaotong.png` 与 `styles.css` 中的 `.mascot-zone` 状态样式；业务页面按当前查询状态设置 `data-state`。回答正文应引用现有记录、事件和影像对象，不由本项目生成。

设计边界：检索扫描只运行一轮；页面隐藏时暂停；系统“减少动态效果”开启时停止运动；红色预警弹窗出现时由集成方在 `.mascot-zone` 上设置 `data-paused="true"`。正式界面中形象应保持在 48–88 px，不覆盖证据或操作按钮。
