## 启动一次

1. 在系统设置保留勾选“本次演示允许小瞳自动补齐临时数据”。
2. 点击唯一“一键载入全链演示数据”，等待结果；红色提醒可先收起。
3. 打开悬浮小瞳，用明确对象提问。普通查询和3D定位不要求补齐授权；需要补齐样本或临时素材时先完成上述启动。授权刷新或换库即失效。

## 可直接询问

| 问题 | 实际响应 |
| --- | --- |
| `哪个传感器异常？` | 读取当前未关闭事件，列编号、测点与等级 |
| `全校现在监测如何` | 按本地快照给楼栋/测点/事件摘要 |
| `B03-F2-CRACK01怎么样` | 最新有效读数、来源、时间、质量与关联事件 |
| `分析 B03-F2-CRACK01 的裂缝照片` | 检查同点素材，按授权补缺，实际计算区域差异；半屏给数值、趋势、照片与证据，不自动换页 |
| `分析 B03-F2-CRACK01 的视频首末关键帧` | 读取当前同点视频或登记内置素材，抽三帧，核对可比条件并实际计算 |
| `分析这段视频` | 有明确同点上下文时保留当前视频；上传文件机位未核实不输出变化比例 |
| `提取这段视频的三个关键帧` | 同点三帧带时间码，重复复用 |
| `播放 B03-F2-CRACK01 的公开实拍视频` | 播放/抽帧；移动机位如实说明不能比对，不套模拟片比例 |
| `视频变化和传感器读数一致吗？` | 说明同步时间未核实，不宣称真实一致 |
| `在3D中定位 B03-F2-CRACK01` | 复核档案后直接打开同楼栋同楼层同测点，不写业务表 |
| `这个问题处理到哪了？` | 在已选事件/测点上下文中核对真实事件→问题→工单→复查阶段，给原表单入口 |
| `准备 B03-F2-CRACK01 的巡检任务` | 授权后查待办，缺少才调用既有计划/任务入口，打开任务；签到仍由人模拟读卡 |
| `补齐 B03-F2-TILT01 的监测数据` | 授权下复用近期有效样本或补缺，打开同点趋势 |
| `查看操作记录` | 本次请求的新增/复用/失败与真实对象ID，按主键去重 |
| `停止自动补齐` | 撤销之后的准备授权，保留已保存数据；普通查询与3D定位仍可用 |

可续问“读数恢复了吗？”“这组照片中的完好墙面有没有变化？”“把前后裂缝照片放大给我看”。没有对象先选择，不猜某面墙，不给别的传感器借照片。当前影像素材登记在B03-F2-CRACK01。

派工、接单、维修提交、验收、复查、关闭仍在人办原表单；不调用外部AI、摄像头或真实NFC。读数是预设数据，照片是公开实拍与模拟派生，视频像素变化不能换算毫米。回答内容按实际计算，不为了展示制造新变化。

## 新问法与照片交互（2026-10-07，本轮已实施）

1. 首页无对象只给全校/待办/能力帮助，不默认二层裂缝；问“全校哪里异常？”“小瞳能帮我做什么？”“怎么上传照片？”。
2. 问“3号教学楼二层裂缝怎么样”用楼层定位原点；问三层裂缝时有两点则选择，不猜第一条。不存在楼层如实报缺。
3. 影像页选择原B03-F2-CRACK01后，点照片推荐或原视觉证据按钮，回答中点“前后滑杆”移动分界，点“差异叠层”看橙色真实变化像素；这不是裂缝识别或毫米测量。
4. 点击对照结论切完好区，比例/框/叠层一起重算，同照片同一轮；追问“为什么照片有差异”解释最后所选区，所以完好区应答0%，不是固定裂缝15.1%。
5. “放大趋势图”给趋势预览与完整趋势页入口，不是回答内趋势缩放；“放大当前照片”走照片已有缩放。
6. 页面换倾角但上轮仍裂缝，问“它怎么样”给两个具名候选；点击后原问题继续。问“当前选中的测点怎么样”直接用页面，“刚才那个怎么样”沿用上轮。
7. “不要补数据，分析已有视频”只查看当前同点已有视频和分析，缺结果不会自动抽帧、读取内置片或补数据。明确准备仍必须原Settings本次授权。
