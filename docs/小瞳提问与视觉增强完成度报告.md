| 照片滑杆 | 原视觉照片卡提供并排/前后滑杆/差异叠层，保留两张原图ID和同步缩放；滑杆支持鼠标及键盘，未增加素材。 |
| 差异叠层 | 原compareFrames同一循环产生实际变化掩膜，比例和遮罩共用原阈值/区域/采样。橙色仅表示选区内达亮度差阈值的像素，区域外未分析；不可比不给伪热图。叠层透明度可调。 |
| 证据定位 | 对照区域结论变成可点按钮，点击切换原框并重算同一回答；两张照片ID固定，不新增提问轮次。 |
| 追因 | “为什么照片有差异”读取最后有效的同点区域结果并解释统计依据，不复述红色触发原因；旧照片缺失后不给旧结论冒充当前有效结果。 |

## 可以直接问

无对象：首页问“全校哪里异常？”“小瞳能帮我做什么？”“怎么上传照片？”。

明确对象：“3号教学楼二层裂缝怎么样？”“B03-F3-CRACK01的趋势如何？”“B03-F2-CRACK01问题处理完了吗？”。

原二层裂缝视觉卡：“B03-F2-CRACK01的裂缝照片有什么变化？”；有比对结果后问“为什么照片有差异？”；问“放大当前照片”或“放大趋势图”各走自己的目标。

上下文追问：“当前选中的测点怎么样？”“刚才那个读数恢复了吗？”；页面与上轮不同，含糊指代先选择。

已有会话视频：“不要补数据，分析已有视频”；只展示已有分析，缺帧/结果不会自动补齐。新三层墙面没有照片，不借二层素材。
