# 筑瞳 V1.0 冲刺计划

更新日期：2026-09-22（V1-A、V1-B 已完成）  
适用范围：纯前端、IndexedDB 本地演示版。V2.0 再接入 OpenHarmony 南向采集、后端和真实消息通道。

## 1. V1 的交付定义

V1 不是“又多几个页面”，而是让学校安全管理人员可以在同一套本地演示里完成一次可追溯的管理闭环：

```text
实时手工录入 / CSV 模拟设备导入
  → 规则判定与即时提醒
  → 预警事件、通知与转问题
  → 审核、派工、维修、验收
  → 复查观察、保养计划与统计报表
  → 留痕、导出与答辩复现
```

以下不属于 V1：真实 NFC 硬件读卡、真实传感器协议、无人机图像识别、跨设备同步、短信/电话/应用推送、云端 Web 后台。这些能力在 V2.0 以后接入，V1 界面必须继续如实标注“模拟读取”“站内通知已生成”，不把本机演示说成真实外部送达。

## 3. 阶段与验收

### V1-A：预警触发提醒（已完成）

- 手工实时录入或模拟设备上报只在“新建事件”或“等级升级”时提示；同一事件追加证据、恢复待确认不重复打扰。
- 红色采用强提醒弹窗，不使用浏览器原生弹窗；黄色、橙色进入顶栏“预警提醒”中心。
- CSV 模拟设备导入完成后只显示一条批次汇总提醒；同一事件本批次内多次升级只按最终最高等级计算一次。
- 点击提醒可深链进入预警中心的对应事件详情；提醒界面不伪造外部消息送达。

**验收：** 手工录入红色越限值后，能在一次保存后看到事件编号、测点、触发值、通知对象，并在一次点击后进入证据链；导入多条数据时无连续弹窗。

### V1-B：问题池交互收口（已完成）

- 审核出口选择后，实时显示“状态变化 / 下一责任人 / 下一动作 / 是否自动建工单”。
- 问题池状态卡可点击筛选；筛选栏显示匹配条数并可一键清除。
- 详情改为右侧抽屉，关闭后保持列表滚动位置和焦点。
- 人工上报成功后自动定位、打开并高亮新问题；失败不丢位置、描述和照片草稿。
- 审核提交期间禁用重复点击；切换出口时清空不适用的关联字段。
- “无需处理”采用结构化原因（读数稳定 / 非结构部位 / 已当场处理）+ 不少于 10 字说明；已当场处理要求照片或无法拍照原因。

**验收：** 安全管理人员从待审核筛选到提交审核并查看新增时间线，不超过三次主要点击；重复点击不能产生重复日志或工单。

### V1-C：复查与观察期

- 问题待复查时必须登记复查事项、责任人和目标日期。
- 复查结论分“确认恢复 / 继续观察 / 复发转处置”；复发要关联原问题，不能新建无关孤儿问题。
- 逾期复查进入待办和管理统计，不自动把问题关闭。
- 预警事件关闭后若关联问题仍待复查，详情持续展示提示。

**验收：** 工单验收通过后，问题可进入待复查；复查到期未完成可被筛出；复发记录能回看原问题、工单和事件。

### V1-D：设备保养计划与台账

- 为设备建立周期保养计划（周期、负责人、检查项、下次日期）。
- 按周期生成保养任务，保存执行人、措施、材料、照片和下一次保养日期。
- 保养逾期、设备离线和故障工单分别展示，不混成“建筑结构异常”。

**验收：** 一台裂缝传感器可完成“建保养计划 → 生成任务 → 执行留痕 → 更新下次日期”，并可筛出逾期任务。

### V1-E：统计、报表与冻结验收

- 建立三项管理指标：预警响应时长、问题按期闭环率、复查/保养按期完成率；每项注明分子、分母、时间范围和不纳入条件。
- 支持按楼栋、测点、状态、时间范围导出明细 CSV。
- 输出可打印的单事件处置报告：事件、证据、通知、问题、工单、验收与关闭依据同页可追溯。
- 固化六分钟答辩脚本、固定演示数据、备份恢复文件，并完成宽屏、窄屏、键盘焦点、视觉回归验收。

**验收：** 从固定数据集运行全链后，三个指标与明细一致；导出的事件报告可独立说明“为何预警、谁处置、如何验收、为何关闭”。

## 4. 实施顺序

1. 先完成 V1-A 的测试、实机验证与文档同步；
2. ~~实现 V1-B，优先消除答辩时的“找入口、找对象、重复点”摩擦~~ ✅ 已完成；
3. 在已有工单闭环上接 V1-C，保证“验收通过”之后仍有管理动作；
4. 再建 V1-D，避免把设备维护与结构安全事件混写；
5. 最后做 V1-E，所有统计只读取已经落库、可追溯的数据，不在页面临时拼口径。

## 5. V1 冻结门槛

- 全部自动化测试通过，新增功能有领域规则和仓储写入回滚测试；
- 单文件不超过 450 行、函数不超过 80 行、每层目录文件不超过 8 个；
- 数据一致性检查无错误；
- 从“预警触发”到“复查/关闭”可在本地浏览器稳定复现；
- 演示材料中明确区分已实现的本机站内提醒与未接入的真实外部通知。
