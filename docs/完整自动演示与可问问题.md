# 完整自动演示：启动方式、提问流程与可问问题

更新：2026-10-08（可问清单再次核对）。现场入口：系统设置 → **开始完整演示**。服务端口以实际启动结果为准，先核对页面标题为筑瞳；演示工作区 URL 使用 `?workspace=showcase#/settings`，不要把历史端口当作当前服务保证。

## 现场怎么用

点击一次“开始完整演示”，系统进入独立演示库，自动准备历史案例、比较读数和媒体，串行执行 23 个阶段。主案例完成采样、黄→橙→红升级、确认、创建与审核问题、派工、接单、维修照片、验收照片、恢复复测、登记复查、确认恢复、关闭事件，随后展示其他指标、3D、双点比较、试算、视频、回放、案例、巡检、保养和最终报告。无需人工补表、换身份或上传演示附件。

最终看到“23/23 · 完整演示已完成”和实际处置报告。需要再展示一次，点“重新演示”；复位只作用于 `zhutong-showcase`。返回主库使用顶部“返回主库”。主库仍为 `zhutong-demo`。

## 手动操作也可以（2026-10-14恢复）

系统设置顶部“手动操作演示”→“一键载入全链演示数据”。它准备14类场景，导入后不启动自动流程或跳页；待处理案例和历史样例都可打开。选B03-F3-CRACK01的实际待确认事件从头操作，原二层点演示照片/视频，历史三层西墙查看完整闭环。小瞳补齐授权可选、默认不勾。若当前URL含workspace=showcase，先点“返回主库，准备手动演示”，再用原按钮；不往23阶段自动库混入旧全链。手动与自动都在同一设置页，无需新增页面入口。旧标签Ctrl+F5刷新即可，不清站点数据。

## 提问流程

启动演示 → 自动确定主案例与本阶段对象 → 点击自由提问或输入问题 → 当前提交结束后暂停 → 读取稳定数据或只读试算 → 显示结论、编号、证据与缺项 → 最多三个相关追问 → 继续演示。

暂停后，顶部“可问问题”提供六类按钮，点击时绑定主案例；比较按钮明确指定两条三层裂缝测点。“自由提问”优先沿用当前阶段回答的上下文，没有阶段回答时才回到二层主案例。因此比较后不要直接把“当前事件”理解为主案例，切换主题优先点对应预设按钮。自由输入涉及两个候选时，保留原问题、已定测点与范围，点候选后继续。比较后问“它怎么样”会要求选一个点；“改看7天”继续原两点。相对范围共用演示时钟，自定义日期包含首尾本地日期。

普通查询、历史回放与阈值试算不修改规则、事件、工单或业务审计。视频读取与分析只更新会话素材；像素差异占比不能换算毫米。自动办理只在明确启动的演示任务中执行。

## 可直接照读的演示顺序

先开始完整演示。需要中途讲解时点“自由提问”，等待当前步骤提交结束后暂停；也可等23/23完成后集中提问。每次发一句，拿到回答再追问。中途缺少尚未生成的事件、工单或素材是正常缺项，继续相应阶段后再问。

| 顺序 | 首问 | 随后追问或操作 |
| --- | --- | --- |
| 1 全校概况 | `全校现在监测如何？` | `全校有哪些异常？`；完整演示关闭主事件后，未关闭队列不必再包含它 |
| 2 主案例读数 | `B03-F2-CRACK01 现在的读数是多少？` | `B03-F2-CRACK01 的趋势如何？`、`读数恢复了吗？` |
| 3 照片证据 | `分析 B03-F2-CRACK01 的裂缝照片` | `这组照片中的完好墙面有没有变化？`、`为什么照片有差异？`；手动切前后滑杆、差异叠层 |
| 4 视频证据 | `分析 B03-F2-CRACK01 的固定机位模拟变化视频首末关键帧` | `播放第二个关键帧`、`视频变化和传感器读数一致吗？` |
| 5 空间位置 | `在3D中定位 B03-F2-CRACK01` | 核对同楼栋、楼层和编号；3D是档案示意 |
| 6 双点比较 | `比较 B03-F3-CRACK01 和 B03-F3-CRACK02 最近24小时的读数` | `改看最近7天`、`哪个峰值更高？`；点击趋势链接看完整图 |
| 7 事件回放 | 点击顶部预设 `回放当前事件的升级过程` | `什么时候变成红色？`、`当时依据哪条记录？` |
| 8 历史案例 | 点击顶部预设 `以前有类似的裂缝问题吗？` | `它们匹配了哪些条件？`、`历史案例怎么处理的？` |
| 9 阈值试算 | 点击顶部预设 `试算黄色阈值改为0.15毫米，最近7天哪些记录会改变等级？` | `只看等级变化的记录`、`改看最近30天`、`取消试算` |
| 10 处置结论 | 点击顶部预设 `现在办理到哪一步了？` | `还缺什么？`、`打开完整处置报告`；点击回答中的报告链接 |

第7–10项用顶部预设重新绑定二层主案例，避免沿用双点比较或另一个测点的上下文。查询“打开报告”“打开历史案例”“打开趋势”主要返回可点击入口，不承诺输入后自动跳页；明确3D定位和视频关键帧定位有对应执行接线。

## 扩充问题库：首问与连续追问

下表每一行是独立话题。同一行追问沿用上句对象与范围，跨行时先明确对象或重新点预设。

| 类型 | 可以直接输入 | 前提与结果 |
| --- | --- | --- |
| 能力帮助 | `小瞳能帮我做什么？`、`怎么上传照片？` | 帮助说明；询问方法不会自动准备材料 |
| 异常队列 | `哪个传感器异常？`、`列出还没处理的预警` | 当前未关闭事件，不是设备联网故障列表 |
| 楼层定位 | `3号教学楼二层裂缝怎么样？`、`3号教学楼三层裂缝怎么样？` | 三层两点需点选；不存在楼层不借别层回答 |
| 质量对照 | `B02-F2-TILT01 状态怎么样？` | 最新有效读数，存疑和无效值不当作有效异常 |
| 旧采样 | `B04-F1-VIB01 状态怎么样？` | 显示时间与新鲜度，不据此断言离线 |
| 温湿度 | `B01-F2-TH01 状态怎么样？` | 读取同点温湿度；无数据如实说明 |
| 单点趋势 | `B03-F2-CRACK01 的趋势如何？`；随后 `放大趋势图` | 给预览及完整趋势页链接，不是回答内手势缩放 |
| 照片放大 | 照片回答后问 `放大当前照片`、`把前后裂缝照片放大给我看` | 当前有效照片对；不更换素材 |
| 照片追因 | `B03-F2-CRACK01 为什么照片有差异？` | 先有分析；解释最后所选区，不固定回答裂缝区比例 |
| 公开实拍 | `播放 B03-F2-CRACK01 的公开实拍视频`；随后 `这段视频为什么不能比对？` | 明确切换公开片；移动机位不输出可靠变化比例 |
| 视频抽帧 | `提取这段视频的三个关键帧` | 先明确同点视频；有结果则复用 |
| 视频定位 | `播放第一个关键帧`、`播放第二个关键帧`、`播放第三个关键帧` | 有当前视频及相应有效帧，按真实时间码定位 |
| 只读视频 | `不要补数据，分析已有视频` | 仅查看已有会话视频与结果；缺帧不自动抽帧 |
| 比较补选 | `比较两个裂缝测点最近24小时的读数` | 无两点上下文时依次点候选；明确两编号更适合现场 |
| 比较范围 | 比较后问 `改看最近7天`、`改看最近30天`、`改看最近90天`、`改看全部历史` | 当前支持这些预设，不把“最近3天”等未识别表达当有效范围 |
| 指定日期 | `比较 B03-F3-CRACK01 和 B03-F3-CRACK02 在2026-10-01至2026-10-08的读数` | YYYY-MM-DD两个日期，含首尾本地日；可替换日期，空范围不补造数据 |
| 比较结果 | 比较后问 `哪一个区间峰值更高？`、`打开这两个点的趋势` | 同字段/单位才计算差值；跨指标分卡，不硬排大小 |
| 按编号回放 | `回放 B03-F2-CRACK01 的事件升级过程` | 同点多事件会让你选择；也可在句中使用页面真实事件号 |
| 回放追问 | `什么时候变成红色？`、`当时依据哪条记录？` | 先选事件/回放节点；引用历史证据，不重造历史 |
| 查相似案例 | `B03-F2-CRACK01 以前有类似的裂缝问题吗？` | 按明确字段匹配，展示理由、措施、验收与复查缺口 |
| 查看案例 | 案例列表后问 `打开第一个历史案例`、`打开第二个历史案例` | 仅实际存在该项时使用；返回该案例及链接，不自动套用历史措施 |
| 明确对象试算 | `B03-F2-CRACK01 试算黄色阈值改为0.15毫米，最近7天哪些记录会改变等级？` | 0.15是候选演示值，非安全阈值建议；未指定等级沿原阈值 |
| 试算续问 | `只看等级变化的记录`、`改看最近30天`、`取消试算` | 先有候选试算；取消清候选，不改原规则 |
| 进度与报告 | 主事件上下文中问 `现在办理到哪一步了？`、`还缺什么？`、`打开完整处置报告` | 分别核对工单、问题、复查及事件，不用一个状态代替全部 |
| 上下文控制 | `当前选中的测点怎么样？`、`刚才那个怎么样？`、`它怎么样？` | 分别指页面/上轮；双点或上下文冲突时具名选择 |

## 提问与操作的边界

- 当前已接通双测点、预设/明确日期范围、事件回放、案例、试算、视频帧定位和完整报告。旧文档“这些尚未开发”的判断已过时；任意复合长指令、任意自然语言时间范围仍不作支持承诺。
- 照片/视频自动素材仍仅绑定B03-F2-CRACK01；三层两点主要用于数值比较及独立案例，不能借二层墙面影像作证据。
- 完整演示的自动办理来自“开始完整演示”的任务授权，作用于独立库；普通小瞳提问不会派工、验收或关闭事件。“继续演示／重试”“重新演示”“暂停”使用顶部按钮，不将它们写成已支持的聊天口令。
- 主库原按需准备仍使用设置全链按钮授权，可问 `准备 B03-F2-CRACK01 的巡检任务`、`补齐 B03-F2-TILT01 的监测数据`、`查看操作记录`、`停止自动补齐`。这组准备操作不是完整自动演示的暂停/继续控制；“查看操作记录”是小瞳按需请求回执，不等于全部23阶段日志。
- 数据状态随演示阶段、人工操作和所在工作区变化，不预设每次都是红色、每次都有未关闭事件或试算一定改变等级。模拟数据、影像来源与历史耗时标注继续保留。

## 可问问题与验收口径

| 任务 | 问法和追问 | 必要上下文 | 预期结果 | 负例／缺项表现 |
| --- | --- | --- | --- | --- |
| 双点比较 | 比较两个裂缝测点最近24小时的读数；改看7天；哪个峰值更高？ | 两点；默认24小时，预设按钮给定B03-F3-CRACK01/02 | 最新值、峰值、差值、各自记录编号；共用时间域的两条趋势 | 未指定两点列候选；空范围提示改看7天；不同指标或单位分卡，不能混单位算差 |
| 事件回放 | 回放当前事件的升级过程；当时依据哪条记录？ | 演示主eventId，或明确事件号 | 原升级节点、证据编号、规则版本；关联问题复查 | 同点多事件列候选；无证据不补造旧状态；历史阈值不按今天的规则改写 |
| 相似案例 | 以前有类似的裂缝问题吗？；历史案例怎么处理的？；它们匹配了哪些条件？ | 主测点／当前事件／问题 | 排除当前后的总数、前5条、同指标/异常类型/楼栋理由、措施与复查、原报告链接 | 无案例明确空态；未完整办结逐项列缺口；不存在第二条时不推荐打开第二条 |
| 批量试算 | 试算黄色阈值改为0.15毫米，最近7天哪些记录会改变等级？；只看等级变化的记录；取消试算 | 主测点，候选阈值与范围 | 原判定、候选判定、改变条数与排除依据；未指定的等级沿原阈值 | 黄>橙、NaN等校验拒绝；无采样时规则说明缺项；“修改规则”不误保存，不走候选试算 |
| 视频 | 分析当前测点的视频；播放第二个关键帧；为什么不能比较？ | 当前测点视频登记和有效帧身份 | 实际解码抽帧、时间码、播放器定位、裂缝区/控制区差异与可比条件 | 缺视频不借其他测点；会话失效说明；机位不满足条件不输出变化占比；无毫米换算 |
| 办理进度／报告 | 现在办理到哪一步了？；还缺什么？；打开完整处置报告 | 主eventId | 当前真实业务阶段、还缺事项、关联问题/工单/复查和报告链接 | 未选事件不猜；验收通过不能当作问题或事件关闭；未复查、未验收各自列缺口 |

完整办结同时要求：问题关闭、有复查结论、所有关联工单验收通过；有关联事件时事件关闭。历史案例的预设时间明确留有导入说明，不能当作实际办理耗时。

## 暂停、失败与恢复

- 暂停、提问或停止等待在途步骤结束，已经提交的结果保留。
- 继续与重试从当前阶段的数据库状态继续，主链不重复采样、建问题或建工单；准备历史和巡检支持中断重试。
- 刷新后运行恢复为暂停，不能自动重做业务。视频会话需在明确视频问题时重读随包文件并分析。
- 两标签同时开始，只允许取得浏览器独占锁的一方办理，另一方展示具体阻止原因。
- 已完成后自由提问保持“已完成”。运行中原页面和办理表单暂不可编辑，暂停后可以查看细节。
