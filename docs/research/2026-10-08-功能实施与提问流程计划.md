预检自动补齐档案、质量对照、近24小时比较记录、经原业务链办结的历史案例、照片及实际解码的视频帧。缺素材或核验失败显示原因。历史准备与主案例执行分开；主案例使用待确认红色场景，随后通过原受控接口逐步办理。

23阶段自动展示真实页面：准备 → 采样与升级 → 确认 → 问题 → 审核 → 派工 → 接单 → 完工与照片 → 验收 → 连续恢复 → 登记复查 → 复查结论 → 关闭 → 振动/温湿度/质量 → 3D → 比较 → 试算 → 视频 → 回放 → 案例 → 巡检 → 保养 → 报告。每次提交后重读状态；报告前核对主案例真实闭环。

暂停/继续/停止/重试/重新演示均已接线。提问在事务结束后暂停；完成阶段不重复提交；刷新恢复暂停；Web Locks只允许一个标签执行。重新演示只重载演示库。角色串行切换并还原。原页面保留供暂停后查看，自动运行期间表单不能穿插编辑。

## 六项功能

| 批次 | 已实施内容 | 验证重点 |
| --- | --- | --- |
| A 比较 | 默认24小时；24小时/7/30/90天/全部/自定义；共用范围与时钟；两点同字段同单位给最新值差、峰值差、较高点和证据编号，不同单位分卡 | 自定义含首尾，末日次日00:00排他上界；两序列同一时间域；空范围明确提示 |
| A 回放 | 独立回放组件，接事件详情和回答卡，引用事件证据/替代证据/升级/时间线及问题复查 | 只依据原始记录，规则版本不回写，缺历史不推测 |
| B 案例 | 自动准备真实办结历史；按指标、当前异常类型匹配，同楼栋优先；排除当前，前5条与总数 | 关闭＋复查＋全部工单验收＋关联事件关闭，缺项逐一显示 |
| B 试算 | 抽取共享有限值/单调阈值校验；原assessRecord逐条推演，范围前历史参与连续条件 | 规则/事件/工单/业务审计零写入；追问沿候选；取消清草稿；保存指令不误试算 |
| C 视频 | 原播放器三帧时间轴与定位，实际首末帧区域分析，第二关键帧追问 | 视频和帧身份一致，失效不能串素材；输出像素比例，不输出毫米 |
| C 报告/回执 | 中文状态与复查写入原报告；共享事务观察器仅在commit成功后重读生成回执；复用分支统一标记 | 编号、前后状态、实际操作者、时刻、真实附件数、创建/更新/复用、办理入口；回滚不报成功 |

报告与回执保留原事务边界和已返回实体；共享观察器覆盖事件、问题、工单、巡检和保养提交，无需新增业务表。回执缓存保留最近100条，属于界面缓存，审计与报告仍以数据库为准。

## 提问流程

启动 → 当前对象绑定 → 提问暂停 → 读取/试算 → 结论与证据 → 最多3个追问／继续。预设按钮提供六类问法；歧义保留原问题与已确定条件。普通问答不自动办理，明确视频请求可重读会话素材，自动办理只由已启动的任务执行。
