# 筑瞳 App 0.9：功能与身份操作表

2026-11-01。身份在「我的」直接切换，无账号密码。所有操作仍受服务端楼栋范围、对象状态和版本约束。

## 操作对照

| 功能 | 使用身份 | App入口与操作 |
| --- | --- | --- |
| 监测、设备状态、趋势、统计 | 五种身份，按授权范围查看 | 监测→测点详情/趋势/守护统计 |
| 小瞳知识与业务问答 | 五种身份，按授权范围 | 小瞳；问题、工单和办理表单也可带对象提问 |
| 独立现场上报 | 五种身份 | 工作台→现场发现→记录新的现场发现；测点详情也可直接上报 |
| 执行点检/巡检 | **任务计划指定的执行角色**，通常为巡检人员 | 任务→检查任务→巡检手账→到点→清单→提交本测点 |
| 巡检异常上报 | 当前任务的执行角色 | 清单异常→上报这处异常；位置、任务自动带入 |
| 审核六类分流 | **学校安全管理人员** | 工作台→待审核发现→问题详情→审核并安排下一步 |
| 原问题退回补证 | **原上报身份本人** | 工作台→需要补充材料，或问题详情→补充材料；审核要求新照片时必须添加 |
| 手工建维修单 | **学校安全管理人员** | 任务→维修工单→新建维修工单；创建后继续派单 |
| 派单 | **学校安全管理人员** | 工作台→待派工，或审核转维修后进入派单卡片；选维修/物业身份和截止日期 |
| 接本人派单 | **被派工的维修人员或物业人员本人** | 工作台→我的待接单→工单→接单，开始处理；正常接单不再要求确认 |
| 物业代接 | **物业值班人员** | 任务→维修工单→切换全部可见→工单→说明原因并代接 |
| 维修完工 | **实际接单人** | 工单→填写措施，提交完工；维修措施必填，材料、照片选填 |
| 处理验收退回 | 被派工人/依法代接的物业身份；完工仍由实际接单人提交 | 工单查看退回意见→重新接续办理→补充措施→再次提交 |
| 验收通过/退回 | **学校安全管理人员** | 工作台→待验收维修→工单；填写意见，必要时添加验收照片 |
| 登记复查、提交结论 | **学校安全管理人员** | 工作台→待复查→问题详情；先登记事项/责任人/日期，再选择恢复、观察或复发 |
| 确认预警 | **学校安全管理人员** | 监测→预警详情→确认预警，开始跟进 |
| 现场排查、处置措施 | **学校安全管理人员、物业值班人员** | 预警详情→登记排查/处置措施 |
| 预警转关联问题 | 五种身份，按授权范围 | 预警详情→记录关联问题；提交后仍由安全管理审核 |
| 关闭预警 | **学校安全管理人员** | 恢复待确认预警→核查恢复并关闭；服务端要求连续恢复复测及处置依据 |
| 设备保养执行 | **安全管理、物业、设备管理、维修人员** | 任务→设备保养任务→清单、措施及下次日期；异常可转问题 |
| 离线巡检 | 下载任务所指定的执行角色 | 我的→离线随身包→下载→离线填写清单与异常；入队不代表检查完成 |
| 未接单维修草稿 | **被派工的维修/物业本人** | 工单→先填写维修草稿，或下载后的随身包；只保存文字和照片，须联网接单后核对新版本 |
| 离线维修完工 | **已由服务端确认接单的本人** | 随身包→离线维修草稿；入队不代表已完工，服务端确认后生效 |
| 离线保养/上报/补证 | 原有业务相应身份 | 办理页保存为待同步；同步时重新校验权限、状态及版本 |
| 同步及冲突处理 | **原草稿身份** | 工作台→离线草稿与同步异常，或我的→离线随身包；切回身份后明确恢复 |
| 演示准备、模拟采样、暂停/继续、复位 | **完整范围的学校安全管理人员** | 我的→选择比赛演示集→比赛演示准备与进度 |

查看权限不等于办理权限。「我的待办」按身份ID筛选；同名人员不能代替本人。物业代接后，被派工人与实际办理人分别留痕。

## 推荐统一演示顺序

1. 两端选择同一个数据集。正式联动使用主业务集；可反复复位的演示使用比赛专用集。
2. 安全管理在比赛演示页「准备待办理数据」，只生成模拟档案、正常样本、巡检和保养待办。
3. 切巡检人员：到点、填写清单、异常上报。或从现场发现独立上报。
4. 切安全管理：审核→安排维修→选择维修人派单。
5. 切被派工人：接单→维修措施/照片→提交完工。
6. 切安全管理：验收。演示退回时，先切维修人返工并再次送验，再验收通过。
7. 安全管理登记复查并提交结论。有关联预警时，再按预警自身恢复条件关闭预警。
8. 网页保持对应业务页可见，观察同一编号、状态、照片及意见更新；正常每5秒读取，后台暂停，失败退避。

**任务检查完成、工单验收通过、问题关闭、预警关闭是四件独立的事。**

## 连接和范围

- Web交付入口：`http://127.0.0.1:8080`；API：`http://127.0.0.1:18000/api/v1`。
- 当前模拟器已有设备端18080→电脑8080的反向映射；App「我的→连接设置」可填 `http://127.0.0.1:18080`。不要沿用旧隔离验收API地址。
- 真机需改为电脑局域网IP的8080入口；当前没有真机，不宣称真机连接、拍照或安装通过。
- 档案、规则、基准及复杂周期计划配置仍在Web；App完成现场与管理业务闭环。
