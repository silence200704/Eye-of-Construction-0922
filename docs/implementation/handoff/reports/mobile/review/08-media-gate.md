## 实现

- 仅隔离completion网关支持一次性媒体响应暂留：匹配精确GET路径、上游200后暂留字节，收到同gateId放行标记或超时才返回原字节。
- 最长8秒，小于App现有10秒读取超时；App与业务API没有更改。超时只证明超时路径，不能当作途中权限校验通过。
- 暂留时其他身份/档案请求和并发读取继续处理，允许工程师在响应未返回时收回当前身份范围。
- 配置与放行只从本地runtime文件读取，没有远程控制接口；记录仅含路径、字节数、SHA、gateId与结果，不保存token或照片内容。
- 新增`--port`与`--runtime`，可另启18014及独立目录，现有18010/18011无需重启。启动前仍须确认端口可用。
- 普通reporting网关的默认转发不暂停；原POST成功后丢响应逻辑保留并有回归。其文件同时按现有Ruff规则格式化，没有重写业务流程。
