## 本批修改

| 项目 | 修改与目的 | 仍需实测 |
| --- | --- | --- |
| 字号适配 | EntryAbility将当前系统字体倍率发布给原生组件；输入框、选择器、文本域随倍率增高；按钮正文可换行，保留最小触控高度；不通过缩小字体解决空间问题 | 标准→特大热更新、冷启动后的实际文字、控件和键盘遮挡 |
| 工作台与导航 | 窄窗口或大字号时指标/快捷入口改为单列，宽窗口保留双列；导航等宽并允许文字换行，读出当前页面；去掉首页固定行高 | 实际不同窗口和大字号下导航、卡片、长标题是否裁切 |
| 现场操作 | 巡检到点/检查反馈移到当前提交位置；长按钮复用现有按压反馈组件；模拟/人工到点及照片类别可换行排列 | 提交位置可见错误，原有输入、选图、到点和完工流程不回退 |
| 动作反馈 | EventView保存具体action，排查/关闭只显示各自动作消息，避免上一个动作的成功文案出现在新表单 | 确认后打开排查、排查后打开关闭、原请求核验和关闭成功反馈 |
| 统计长列表 | 非零对象按频次降序、ID稳定排序，每卡每页最多20项；范围/周期变化重新从第一页开始；零数据明确说明 | 大量非零对象的真实翻页、过滤重置、总数与数据库一致 |
| 减少动效 | 安静模式同时关闭Tab切换动画，原有弹性组件继续遵守动效偏好 | 实际切换与系统读屏焦点/名称 |
