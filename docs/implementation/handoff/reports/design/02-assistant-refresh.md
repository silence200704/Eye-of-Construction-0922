# 7A-Web 补充交付：小瞳助手面板

日期：2026-10-25。按用户截图调整助手面板；底层页面为管理报表。延续校园青主题与校园卡片设计，阶段 7A 整体仍进行中。

## 本批改动

- 空会话改为小瞳欢迎区、能力标签、三张真实快捷提问卡、关注对象提示；背景使用本地 CSS 点阵和柔和光晕。
- 顶部上下文完整换行，保留关闭、清空对话、清除上下文与已授权任务停止入口。
- 有对话后显示提问气泡、回答卡、事实卡与推荐追问；知识引用、对象候选、业务跳转沿用原实现。
- 多行输入支持 Enter 发送、Shift+Enter 换行；中文输入法组合状态与 keyCode 229 不发送。发送与刷新绑定真实 busy 状态。
- 桌面为圆角侧面板，左侧业务页面仍可操作；900px 及以下全屏，内容区独立滚动，输入区保持可见。
- 提取三个局部样式文件，新增欢迎组件与键盘判断小函数，避免继续扩大面板文件。没有新增产品依赖，没有修改助手算法、后端契约或权限逻辑。
