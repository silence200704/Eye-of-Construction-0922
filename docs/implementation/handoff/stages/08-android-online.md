# 阶段 8：Flutter Android 在线现场业务

目标：在 Android 真机完成点检、巡检、问题上报和工单办理，与 Web 使用同一服务端数据。
前置：阶段 5 的业务命令及附件接口通过；阶段 7 的助手不是移动端必须复制的全部功能。
不新增登录页、账号密码，也不声称模拟 NFC 是真实 NFC 读卡或实际到场证明。

## 实施步骤

### 8.1 工程与连接

- 在现有仓库内建立 Flutter 移动端目录，按连接/任务/上报/工单/共享模型组织，避免单一超大页面。
- 固定 Flutter/Dart 与 Android 构建环境，提交锁文件和构建说明，不提交设备密钥或私有配置。
- 提供服务器地址设置、连接测试、版本和错误信息。真机使用电脑局域网 IP 的 8080 同源 API 入口。
- Android 模拟器单独说明宿主机访问地址；不能默认手机的 127.0.0.1 就是电脑。
- 复用五类身份白名单、自动默认身份和身份切换；内部会话失效可恢复，不展示登录表单。
- 状态管理区分远程实体、表单草稿、上传和命令进行中，防止重复点击和迟到响应串身份。

### 8.2 现场工作台与任务

- 首屏突出我的待办、点检/巡检、问题上报和工单，不复制 Web 的完整管理后台。
- 任务列表支持状态、日期和类型；详情显示生成快照、必查点、清单、当前办理进度。
- 查看测点位置/设备资料；到点提供“模拟 NFC 读卡”和“人工签到”，人工原因必填。
- 显示标签不符等失败原因，保留尝试；到点后再填必答清单，缺项和异常未处理不能完成。
- 正常/异常、备注、未检查点和部分完成与 Web 口径一致，最终以命令返回状态为准。

### 8.3 上报与照片

- 支持任务异常转问题及独立人工上报，带原任务/测点/来源关联。
- 照片从相机/相册选择，处理权限拒绝、取消、损坏、超限和压缩失败。
- 按现有照片配额压缩并在上传前提示；服务端仍独立校验，不绕过三张/600 KB 等约束。
- 先得到 mediaId 再提交归属；固定 draftId/submissionId，网络超时重试不能重复建问题或照片。
- 显示上传进度、失败重试、待提交与已提交，未完成上传不能显示服务器证据已保存。
- 本阶段保留表单期间草稿与重试标识；真正断网重启后的持久化队列在阶段 9 验收。

### 8.4 工单办理

- 列表与详情展示派工人、被派工人、来源、措施、材料、前后照片及时间线。
- 维修身份接单、填写维修措施、提交完工；物业代接保留必要原因。
- 安全管理身份完成 Web 验收；首版移动端无需复制所有审核/管理页面。
- 被退回工单展示理由并可再次办理；非法状态或版本冲突先刷新，不覆盖另一端更新。
- 完工提交不自动视为验收、问题关闭或预警关闭。

### 8.5 在线一致性与体验

- 刷新/页面返回重新读取必要事实，正确取消旧请求；会话失效不丢当前草稿。
- 大按钮、清晰必填提示、照片预览、提交状态，支持现场单手操作与常见 Android 屏幕。
- 本阶段无完整离线能力时必须提示不可提交，不能把本地状态写成在线成功。
- 业务页不暴露数据库、令牌和内部技术参数；服务器连接信息放单独设置入口。
- 使用实际安装 APK 测试，调试网页或模拟器单独通过不等于真机通过。

## 交付物

Flutter 源码、Android APK、连接说明、身份/任务/签到/检查/上报/工单页面、
网络客户端与 DTO、媒体流程、flutter analyze/test/build 结果、至少一台真机录屏与接口/数据库核对。

## 必验清单

| 编号 | 验收条件 |
| --- | --- |
| S8-01 | APK 真机安装可启动并连本机服务；无账号密码页面，五类身份切换有效 |
| S8-02 | 列表/详情/范围与 Web 一致，切身份不残留另一身份业务或上传结果 |
