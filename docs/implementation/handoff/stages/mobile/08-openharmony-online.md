## 实施步骤

### 8.1 工程与连接

- 在仓库建立mobile/openharmony，由DevEco创建ArkTS+ArkUI+Stage工程；全部业务页面原生绘制。
- 固定兼容OpenHarmony的SDK/API≥12、DevEco/Hvigor/OHPM和锁文件，先完成编译/签名安装最小实验。
- 记录目标设备/运行环境、系统/API、安装权限；商业HarmonyOS专有Kit不能未经兼容验证直接采用。
- 实测原生网络、系统照片选择、拍照、关系库与沙箱文件能力，不提交设备密钥或私有签名配置。
- 提供服务器地址设置、连接测试、版本和错误信息。真机使用电脑局域网 IP 的 8080 同源 API 入口。
- OpenHarmony模拟器单独说明宿主机地址；不能默认设备127.0.0.1就是电脑，不沿用Android模拟器专用地址假设。
- 复用五类身份白名单、自动默认身份和身份切换；内部会话失效可恢复，不展示登录表单。
- 状态管理区分远程实体、表单草稿、上传和命令进行中，防止重复点击和迟到响应串身份。
- 记录真实构建/单测/UI测试任务与退出码；不以flutter命令、APK或Web预览代替原生HAP验收。

### 8.1A 赛题北向监测、预警与统计

- 工作台/监测/任务/我的四入口；上报为工作台、测点与任务中的主要行动入口。
- 倾角、裂缝宽度、振动加速度读当前服务端记录，显示单位、采样时间、来源、质量和新鲜度。
- 按建筑/楼层/测点类型筛选；设备在线/离线、电量、最近上报时间由模拟设备状态数据提供，缺失显示未知。
- 这些新字段先核对现有模型/契约；必要时做兼容DTO/追加迁移，不能前端写死或伪装硬件在线。
- 历史预警查询/详情、授权确认、现场排查结果和处置措施登记必须在App可操作，维护台账可追溯。
- 复用现有事件/问题/工单命令，权限不符提示移交；不得绕过工单验收/复查和预警关闭条件。
- 原生显示建筑/测点预警频次、传感器类型分布、周/月趋势；按服务端时间与权限聚合，空集显示空态。
- 预警界面可演示灯光图案/提示音，明确“声光模拟”；停播不等于确认或关闭，不声称实体声光模块接通。
- 正常、异常、恢复、设备离线和低电量使用固定独立测试夹具；正式场景准备与复位在阶段10统一接入。

### 8.2 现场工作台与任务

- 首屏兼顾当前预警和现场待办，突出点检/巡检、上报和工单；不复制Web完整管理后台。
- 任务列表支持状态、日期和类型；详情显示生成快照、必查点、清单、当前办理进度。
- 查看测点位置/设备资料；到点提供“模拟 NFC 读卡”和“人工签到”，人工原因必填。
- 本轮不开发真实NFC，人工与模拟来源分开；未来若扩展，另核对后端来源枚举和原生接口。
- 显示标签不符等失败原因，保留尝试；到点后再填必答清单，缺项和异常未处理不能完成。
- 正常/异常、备注、未检查点和部分完成与 Web 口径一致，最终以命令返回状态为准。

### 8.3 上报与照片

- 支持任务异常转问题及独立人工上报，带原任务/测点/来源关联。
- 照片从相机/相册选择，处理权限拒绝、取消、损坏、超限和压缩失败。
- 按现有照片配额压缩并在上传前提示；服务端仍独立校验，不绕过三张/600 KB 等约束。
- 先得到 mediaId 再提交归属；固定 draftId/submissionId，网络超时重试不能重复建问题或照片。
- 显示上传进度、失败重试、待提交与已提交，未完成上传不能显示服务器证据已保存。
- 本阶段保留表单期间草稿与重试标识；真正断网重启后的持久化队列在阶段 9 验收。

### 8.4 工单办理

- 列表与详情展示派工人、被派工人、来源、措施、材料、前后照片及时间线。
- 维修身份接单、填写维修措施、提交完工；物业代接保留必要原因。
- 安全管理身份完成 Web 验收；首版移动端无需复制所有审核/管理页面。
- 被退回工单展示理由并可再次办理；非法状态或版本冲突先刷新，不覆盖另一端更新。
- 完工提交不自动视为验收、问题关闭或预警关闭。

### 8.5 在线一致性、视觉与设备体验

- 刷新/页面返回重新读取必要事实，正确取消旧请求；会话失效不丢当前草稿。
- 按阶段7A实现校园插画、小瞳、状态图案、任务步骤和原生转场；正文与告警区域保持清楚。
- 大按钮、必填提示、照片预览、提交状态支持单手操作、安全区、系统返回、字体放大和不同窗口。
- 手机原生布局与宽窗口/平板预览分别留证，不以Web截图拉伸替代；主要触控目标≥48vp。
- 本阶段无完整离线能力时必须提示不可提交，不能把本地状态写成在线成功。
- 业务页不暴露数据库、令牌和内部技术参数；服务器连接信息放单独设置入口。
- 提供签名HAP与实际安装运行记录；真机、模拟器、预览器分别标记，模拟器通过不等于真机通过。
- 页面使用通用校园/演示角色，正式截图/录屏按匿名要求检查；装饰插画不能成为现场照片证据。
