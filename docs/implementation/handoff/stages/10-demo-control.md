# 阶段 10：比赛演示编排、暂停、复位与报告

目标：用真实业务命令串起五条固定演示路径，可重复、可解释，现场失败能定位和恢复。
前置：阶段 4—9 通过；现有纯前端场景执行器不得继续绕过后端读写。
保留手动准备与自动办理两个用途，清晰区分，不将模拟时间或素材当真实采集结果。
2026-10-24修订：包含阶段7A视觉成果和OpenHarmony原生App；按[赛题范围](../../design/competition-scope.md)
准备纯软件演示，全部硬件输入模拟，不开发板端固件或实体声光模块。

## 实施步骤

### 10.1 环境预检

- 检查 API/数据库/迁移、知识和索引版本、模型与媒体文件、身份、磁盘及演示数据集。
- 检查OpenHarmony运行环境/API≥12、HAP版本/签名、App连通和媒体权限；设备/模拟器分别记录。
- 查寝8000/5173与筑瞳18000/8080同时可用；演示不占用或停止查寝服务。
- 缺文件、索引、模型或未就绪接口显示具体修复项，不进入一半才发现缺依赖。
- 区分外网不可用和本地服务不可用，断外网不应被误判为全部功能故障。

### 10.2 预置数据与场景版本

- 场景只操作指定的 demo-showcase；demo-main 和原浏览器旧库不在自动复位范围。
- 场景清单固定版本，记录对象、输入、模拟时间、素材来源、预期业务条件和展示位置。
- 模拟倾角/裂缝/振动、在线/离线/电量采用固定样本与状态记录，来源可见，缺值不填“正常/100%”。
- 准备数据必须走合法初始化/业务命令并保留来源，不直接篡改状态制造“已验收”。
- 手动准备只建待办理数据，不偷偷执行后续动作；重复准备按场景/业务键复用，保留已办理进度。
- 数据集、场景版本、runId 与每步 operationId 绑定，保证回执可以定位到一轮演示。

### 10.3 五条固定路径

1. 三类模拟读数/设备状态→黄橙红事件→App历史预警、确认/排查/措施与统计→Web证据/趋势/小瞳。
2. OpenHarmony App点检/巡检→模拟NFC/人工签到→清单→异常照片上报→Web审核。
3. 派工→手机接单完工→Web 验收→复查→问题及预警按各自条件关闭。
4. 手机断网办理→杀应用恢复→联网补传→无重复对账。
5. 口语知识提问→对象澄清/上下文追问→引用→正确功能深链。

现有自动演示中的比较、视频、回放、试算、其他指标及保养应归入对应路径和步骤，
不因整理为五条路径而丢失现有展示能力。明确哪些步骤需要人/真机操作，不能伪装为已自动执行。
第一条可播放界面灯光/提示音模拟，必须标记来源；不把页面动画说成实体声光报警。

### 10.4 编排器与暂停恢复

- 场景步骤具有前置条件、命令、固定幂等键、预期后置条件、展示动作和失败恢复入口。
- 保存运行状态与实际回执，暂停、等待人工、失败、完成分别表达。
- 只有业务成功和后置条件满足后才推进；动画/定时器播放结束不能证明业务已完成。
- 自由提问在安全边界暂停，等待当前提交结束；继续时先确认已经提交步骤，不重复办理。
- 页面刷新或 API 重启后恢复为暂停，显示已完成步骤和待办；恢复不自动重放写操作。
- 失败重试使用原操作键；响应未知先核对回执；不能新建一张工单“绕过错误”。
- 通过专用演示时钟模拟超时，并将模拟来源持久化；普通业务仍用真实服务端时间。

### 10.5 安全复位与旧队列隔离

- 复位限全校安全管理身份、明确指定独立演示集，保留复位前备份/报告与素材来源。
- 一个复位命令完成子对象关系处理、基线重建、epoch 递增和回执；失败整体回滚。
- 禁止更换整个运行数据库文件、清空用户/密钥、删除主库或借关闭外键跳过关系。
- 复位后的 ID 即使相同，旧 epoch 请求也必须被拒绝；移动端旧队列进入冲突隔离。
- 复位与其他写入并发时串行保护，避免既接受旧操作又发布新 epoch 的混合状态。
- 旧媒体清理独立于主事务；仍被备份、报告、草稿引用的内容不能盲删，阶段内明确保留策略。

### 10.6 演示核对报告

- 报告从数据库/回执生成，包含场景版本、runId、epoch、真实对象 ID、每步结果和失败原因。
- 核对事件、问题、工单、任务、照片、审计和回执数量及最终状态，不输出固定“全部通过”。
- 支持当前页查看、JSON 导出及适合答辩查看的摘要，保留模拟数据与演示规则标记。
- 一轮场景复位后完整重复至少三次；任意中断/重试不得累积重复业务。

### 10.7 双端演示和宣传成品

- 阶段7A模板替换为同版本Web/App真实截图，关键动作有原生App实录和相同业务ID的Web回执。
- 正式MP4≤5分钟、≤100MB，脚本目标4分30秒至4分50秒，避免开场动画挤占功能展示。
- 准备讲解≤10分钟的PPT、设计方案资料、主海报/场景海报/协同图；额外宣传片不替代正式视频。
- 评审版匿名：封面、UI、通知栏、角色名称、字幕/片尾、PPT备注不暴露学校/队伍/教师身份。
- 宣传准确：原生软件+模拟输入+真实数据库闭环，不将共享后端说成星闪/5G/系统级流转。

## 交付物

服务端场景清单和控制命令、Web 预检/准备/开始/暂停/继续/复位/报告入口、
场景与步骤契约、演示时钟、五条路径脚本、三轮对账与旧队列联测、匿名正式实录与宣传成品。
