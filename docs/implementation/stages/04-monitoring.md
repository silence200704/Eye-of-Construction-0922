1. 恢复状态由完整有效采样序列核验。恢复窗口中任意正常记录修订为越限、存疑或无效，
   会重新判断恢复是否成立；不成立时回到 pending/handling，关闭请求返回 409。
2. 窗口之外的历史越限证据修订，不再无条件撤销后续仍然有效的恢复。
   恢复序列修正回正常后，重新满足条件可以恢复 recovering。
3. 关闭预警时再次读取并核验实际记录，不能仅凭已过期的 recovering 状态关闭。

5. 恢复状态、修订历史、审计与幂等回执同事务；重放不重复写入。
