# 分阶段开发与验收门槛

每阶段按“理解旧行为 → 行为测试 → 后端实现 → 客户端接入 → 验证 → 阶段报告”推进。
新增关键业务先验证失败用例，再实现并验证通过；保留本地 Git 检查点。

| 阶段 | 开发内容 | 必须通过的门槛 |
| --- | --- | --- |
| 0 | 原代码基线、功能与数据盘点、环境检查 | 可恢复原代码；原测试与构建结果可追溯；数据有迁移去向 |
| 1 | FastAPI、配置、SQLAlchemy 会话、日志、身份切换、HTTP 客户端、开发代理、基础 Docker | Web 直接进入工作台，无账号密码；身份切换与刷新恢复通过；无效身份与令牌被拒绝；启动可重复 |
| 2 | 业务模型、约束、Alembic、媒体上传关联、备份基础 | 空库升级成功；约束、回滚、文件校验及重启持久化通过 |
| 3 | IndexedDB/偏好/内存导出、测试集导入、附件迁移、数量关系核对 | 重复导入幂等；原值、编号、时间、引用与附件可核对；缺失逐项报告 |
| 4 | 档案、版本规则、监测录入修订、CSV、事件、通知、地图趋势 | 与旧行为样例结果一致；历史版本解释、预警升级恢复关闭及跨浏览器读取通过 |
| 5 | 点检巡检、问题审核、工单、复查、保养、报表、回执 | 全闭环通过；角色、重复提交、事务回滚和双向关联通过 |
| 6 | 知识维护、分块、FAQ、同义词、本地模型、SQLite 向量、混合召回 | 断外网语义检索通过；知识启停及版本切换正确；标注问集校准留证 |
| 7 | 业务直答、知识解释、澄清、多轮、追问、引用、深链、会话保存 | 回答事实与数据库一致；无依据不补造；不串对象；现有视觉和回放行为回归通过 |
| 8 | Android 身份切换、任务、虚拟 NFC、人工签到、照片、问题、工单 | 无登录界面；真机在线提交与 Web 数据一致，完整处理链路通过 |
| 9 | 本地缓存、草稿、文件队列、幂等同步、版本和 epoch 冲突 | 断网填写、重启恢复、补传、不重复、不覆盖和切账号隔离通过 |
| 10 | 环境检查、预置场景、自动步骤、暂停恢复、复位、报告 | 五类脚本可重复运行；失败重试不建重复单；旧队列不能污染新场景 |
| 11 | 回归、真机、断外网、备份恢复、镜像与模型离线包 | 另一环境按说明启动成功；数据库媒体知识完整；固定演示问集全部通过 |

## 固定演示路径

1. 异常监测 → 预警 → 助手解释 → 证据与地图。
2. 手机巡检 → 虚拟读卡/人工到点 → 清单 → 照片上报 → Web 审核。
3. 派工 → 手机接单完工 → Web 验收 → 复查。
4. 手机断网办理 → 联网补传 → 检查无重复。
5. 口语知识问答 → 上下文追问 → 依据与功能跳转。

## 交付与范围

交付 Web、API、Android APK、迁移工具、测试数据基线、媒体、本地模型、索引、
Docker 离线镜像及操作说明。默认 Windows Docker 本机、局域网真机联调。
首版助手主要在 Web 展示；Android 聚焦现场业务。现有演示预警规则仍是演示规则。
所有新动态语言文件尽量 ≤450 行、Dart ≤500 行，函数 ≤80 行、参数 ≤5 个，目录文件尽量 ≤8。
