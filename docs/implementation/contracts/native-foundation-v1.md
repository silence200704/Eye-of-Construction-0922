# 原生在线基础 v1

2026-10-26；包名org.zhutong.mobile。复用现有HTTP/监测/现场业务契约，不新增服务端端点。
此文保留基础批次的只读边界；2026-10-28新增巡检写入见[原生巡检契约](mobile/inspection-v1.md)。

## 身份与读取

1. 读取`GET /demo/identities`，限定safety/property/device/inspector/repair五类服务端身份。
2. `POST /demo/identity`取得内部会话；`GET /auth/me`校验真实身份、角色和楼栋范围。
3. 档案→监测记录→事件→检查任务→工单形成完整Workspace；每步检查请求代次及datasetEpoch。
4. 完成后再次读取当前身份，比较id/role/排序后的buildingIds；范围变化不发布半批或旧权限数据。
5. 401只允许用同一身份恢复一次；403不改成更高权限身份。

地址采用HTTP/HTTPS服务根，不接受内嵌凭据、查询串或任意路径。令牌仅保存在网络对象内存中。
身份/连接变化即清除受保护快照和详情导航、取消旧传输；任何晚到await结果先核验请求代次。
页面隐藏使在途恢复失效，返回前重新核验已保存身份。业务数据没有浏览器临时数据回退。

## 展示与本地偏好

- 首页计数以当前授权快照计算；未连接/失败显示“—”，不显示之前身份的8/1。
- 监测最新值按采样时间排序，补录到达较晚不覆盖当前采样。缺少值显示未知；历史/模拟来源明确。
- 预警类型筛选按事件所属测点，历史模式包含对应类型的已关闭事件。
- 详情最近5条载入记录，显示原始编号、采样时间、质量、来源和服务端规则版本。
- 检查任务与工单读取服务端空集则为空态。本版不创建演示任务，不提交业务写命令。
- 连接Preferences只保存成功baseUrl/identityId；Appearance Preferences只保存motion，均串行flush。
- “轻动效”只影响装饰反馈，不改变权限/请求/业务结果。关闭后仍能切页，进程重启后保留。

阶段8后续批次接到点、上报/照片、办理、跨端冲突和统计；阶段9再接离线草稿/队列/同步。
不把内存缓存当离线持久化，不把模拟器通过当真机通过。
