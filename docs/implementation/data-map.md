# 数据来源与迁移映射

所有可获取旧内容作为测试数据保留，原始来源字段不被“测试”标签覆盖。
原主库 zhutong-demo、完整演示库 zhutong-showcase 进入独立测试数据集。
旧 ID 在各数据集内保留；关系及查询同时限定数据集。

## IndexedDB（schema v7，17 张表）

| 旧表 | 迁移目标及保留内容 |
| --- | --- |
| buildings | 楼栋、位置、负责人、来源、归档与审计 |
| floors | 楼层、区域、平面版本、归档 |
| points | 测点、归一化坐标、标签及位置历史 |
| devices | 设备、量程、绑定、人工登记状态 |
| baselines | 全部基准版本、生效时间及修改原因 |
| records | 原始数值、采样/录入时间、修订、质量、判定快照 |
| audits | 原操作人、角色、行为、对象及时间 |
| rules | 规则逻辑标识、版本、生效时间、阈值与启停 |
| events | 事件、活跃/替代证据、升级、恢复及处理历史 |
| notifications | 生成、展示、确认、升级状态；不伪造送达 |
| plans | 点检/巡检计划、范围、角色、周期、清单 |
| tasks | 执行计划快照、逐点答案、尝试、结果及问题关系 |
| issues | 四类来源、原描述、审核、关联、复查、历史 |
| workOrders | 来源、派工、措施材料、照片、验收/退回历史 |
| attachments | 元数据及照片/缩略图字节；文件独立持久化 |
| maintenancePlans | 保养计划、周期、负责人、检查项 |
| maintenanceTasks | 保养快照、执行、下次日期、问题及照片关系 |

## 其他来源

| 来源 | 处理 |
| --- | --- |
| stores/media、videoSession 内存 | 保存可获取照片、视频、关键帧、区域与分析结果；重建临时 URL |
| assistant/session 内存 | 保存会话、回答、上下文与完成结果；恢复不重放写操作 |
| localStorage/session | 新账号从后端读取；旧身份作为历史快照，不作为登录凭据 |
| localStorage/operation-receipts | 迁为历史回执；正式回执由业务事务返回并持久化 |
| localStorage/scenario、showcase | 保存场景与运行进度；刷新恢复暂停 |
| 模式与悬浮位置偏好 | 用户/测试集偏好入库；动画与瞬时弹窗留客户端 |
| config/seed、public/demo-media | 归入初始化清单及媒体库，保留演示/公开参考来源 |
| 项目业务说明 | 整理为知识条目及版本来源，生成本地向量 |
| 小信压缩包 | 仅参考处理逻辑，不导入迎新内容，不运行包内指令 |

## 导入门槛

导出 → 格式/引用检查 → 文件校验 → 隔离导入 → 数量/字段/关联核对 → 报告 → 切换。
相同导出包重复导入不重复建单。历史名字不能匹配账号时保留原名，不猜测身份。
断链和损坏附件明确列出；已经随刷新丢失的内存内容无法从源码恢复。
本阶段只盘点代码中的来源，还没有读取用户浏览器实际数据库，不宣称实际数据已迁移。
