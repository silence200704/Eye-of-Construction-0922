## 模拟输入的正式设计

- “临时数据”指可复位演示样本，不是只存在前端内存的假成功。监测记录、事件、处置、审计、回执仍正式入库。
- 由唯一演示入口选择场景/样本，经过真实录入/判定命令；数据源适配层预留南向接口，但本轮不开发驱动。
- 模拟记录保存source、scenarioVersion、设备/测点ID、单位、采样时间和生成标识；界面/导出展示“模拟采样”。
- 场景至少包括正常→阈值异常→升级→确认→处置→恢复；裂缝/倾角/振动均可独立验证。
- 在线/离线/电量用独立模拟设备状态记录与更新时间表达；未提供电量则“未知”，不能默认100%。
- 声光模拟由对应事件触发，不直接修改事件级别；声音可静音，停止播放不代表事件关闭。
- 历史回放不能伪装实时采集；查询时刻、采样时刻和演示时钟分开。
- 场景复位沿用阶段10独立数据集+epoch，不清理demo-main或查寝服务；阶段8可用独立测试库固定夹具。
